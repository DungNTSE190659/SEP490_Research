# Beyond AUC: Prediction vs. Sequencing Utility in Knowledge Tracing

Reproducible pipeline for the research study: *"Beyond AUC: Do Better Knowledge-Tracing Models Make Better Tutors? Evaluating Prediction vs. Exercise-Sequencing Utility across Math and Programming"*.

This codebase evaluates how well offline predictive accuracy (AUC/RMSE) correlates with downstream exercise-sequencing utility via simulator-based evaluation, across standardized math and programming datasets.

> **Note on reproducibility:** All experimental numbers are generated by running these scripts. The codebase relies on standardized public datasets.

---

## 1. Install the Python environment

```powershell
# from the code/ folder, Windows PowerShell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

If you have an NVIDIA GPU, install the matching CUDA build of PyTorch from
<https://pytorch.org/get-started/locally/>.

## 2. Install pyKT & EduData

pyKT is installed from source (it is not a stable PyPI package). EduData is used for downloading datasets.

```powershell
git clone https://github.com/pykt-team/pykt-toolkit
pip install -e .\pykt-toolkit
pip install EduData
```

## 3. Download the datasets

Datasets used:
- **ASSISTments2009** (Math)
- **Junyi Academy** (Math)
- **POJ** (Programming)

Use `edudata download <dataset_name>` where applicable, and place the raw files into `data/raw/<dataset>/`.

## 4. Standardise the data

```powershell
python src\prepare_assistments2009.py --raw data\raw\assistments2009 --out data\processed\assistments2009.csv
python src\prepare_poj.py --raw data\raw\poj\poj_log.csv --out data\processed\poj.csv
# python src\prepare_junyi.py ...
```

Each script writes a CSV in the shared schema:
`student_id, order, problem_id, kc_ids, correct, code`.

## 5. Run the pipeline

Everything at once:

```powershell
python src\run_all.py --dataset poj --config-dir configs --out results
```

Or step by step: train each config with 5-fold student-level CV, compute prediction metrics, run the offline sequencing evaluation, then generate LaTeX tables.

## 6. Put results into the report

```powershell
python src\make_tables.py --results results --out ..\report\sections\_generated
```

This writes `table_prediction.tex` and `table_sequencing.tex`. In the report, use `\input{...}` for these generated files.
